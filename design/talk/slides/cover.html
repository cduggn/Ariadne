Ariadne is a LangGraph agent with read-only Kubernetes tools. Each diagnosis is 5 to 24 chained model calls, and each call's prompt extends the last, so the serving problem is long, growing contexts sharing a KV pool. Two headline results: KV was the first limiter, and once admission was sized to KV the overload moved into the gateway's queue, where priority and deadlines apply.
